# Mycelium

A deep-violet [Omarchy](https://omarchy.org) theme built around a glowing psychedelic forest: indigo trunks, ember-amber window borders, and a cyan third eye watching over it all.

## Install

```bash
omarchy theme install https://github.com/Angelo-Tassi/omarchy-mycelium-theme
```

Or open the Omarchy menu (`Super + Alt + Space`) → **Install → Style → Theme** and paste the repo URL. You get the palette, the wallpaper, the amber borders and the bar tint. The rounded corners, blur and see-through terminals in the screenshots come from personal settings and are not part of the theme.

### Tinted bar

To show the bar tint, turn off the bar's fully transparent mode: set `"transparent": false` under `bar` in `~/.config/omarchy/shell.json`.
